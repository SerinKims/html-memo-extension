# 설치 및 배포

## 개발 환경

필수 도구:

- Node.js LTS
- pnpm
- Chrome

권장 패키지 매니저는 pnpm이다.

## 개발 설치 절차

구현 단계에서 사용할 기본 명령은 다음과 같다.

```bash
pnpm install
pnpm dev
```

WXT 개발 모드가 생성한 확장 프로그램 출력 디렉터리를 Chrome 확장 프로그램 관리 화면에서 로드한다.

1. Chrome에서 `chrome://extensions`를 연다.
2. 개발자 모드를 켠다.
3. `압축해제된 확장 프로그램을 로드`를 선택한다.
4. WXT 개발 출력 디렉터리를 선택한다.
5. 조사 대상 페이지를 새로고침한 뒤 확장 프로그램을 실행한다.

## 프로덕션 빌드

구현 후 ZIP 배포 파일은 WXT 빌드 산출물을 기준으로 만든다.

```bash
pnpm build
pnpm zip
```

실제 명령은 WXT 설정과 `package.json` 스크립트에 맞춘다.

## ZIP 배포 방법

1. 개발자가 프로덕션 빌드를 실행한다.
2. 빌드 결과물을 ZIP 파일로 패키징한다.
3. ZIP 파일명에 버전과 빌드 날짜를 포함한다.
4. 사내 파일 시스템, 이메일, 메신저 등 조직이 허용한 파일 전달 방식으로 배포한다.
5. 설치자는 ZIP 파일을 로컬 폴더에 압축 해제한다.
6. Chrome `chrome://extensions`에서 압축 해제된 폴더를 로드한다.

Chrome Web Store 배포는 이 문서의 기본 경로가 아니다.

## 설치자 절차

1. 전달받은 ZIP 파일을 신뢰할 수 있는 위치에 저장한다.
2. ZIP 파일을 압축 해제한다.
3. Chrome에서 `chrome://extensions`를 연다.
4. 개발자 모드를 켠다.
5. `압축해제된 확장 프로그램을 로드`를 선택한다.
6. 압축 해제한 폴더를 선택한다.
7. 확장 프로그램이 표시되는지 확인한다.
8. 테스트 페이지에서 위치 메모를 하나 작성하고 저장 여부를 확인한다.

### 로컬 HTML 접근 허용

로컬 HTML에 메모하려면 설치 후 사용자가 별도로 권한을 켜야 한다.

1. `chrome://extensions`에서 이 확장 프로그램의 `세부정보`를 연다.
2. `파일 URL에 대한 액세스 허용`을 켠다.
3. Chrome에서 `.html` 파일을 연다.
4. Popup의 `메모 시작`을 누른다.

Popup에서 `파일 접근 설정 열기`가 표시되면 아직 권한이 꺼진 상태다. 이 권한은 특정 파일 한 개가 아니라 모든 `file://` URL에 적용되며, 확장 프로그램은 사용자 동작 전에는 Content Script를 자동 주입하지 않는다.

## 업데이트 방법

### 개발 중 업데이트

1. 코드를 수정한다.
2. WXT 개발 모드 또는 빌드를 다시 실행한다.
3. Chrome 확장 프로그램 관리 화면에서 새로고침 버튼을 누른다.
4. 대상 웹페이지를 새로고침한다.

### ZIP 배포 업데이트

1. 새 버전 ZIP 파일을 받는다.
2. 기존 확장 프로그램 폴더와 구분되는 새 폴더에 압축 해제한다.
3. Chrome 확장 프로그램 관리 화면에서 기존 확장 프로그램을 제거하거나 새 폴더를 다시 로드한다.
4. 확장 프로그램을 새로고침한다.
5. 기존 메모 데이터가 유지되는지 확인한다.

확장 프로그램 ID가 바뀌면 `chrome.storage.local` 데이터가 이어지지 않을 수 있다. 운영 배포에서는 고정된 확장 프로그램 키 또는 일관된 배포 방식을 사용해야 한다.

## 데이터 백업

기본 저장소는 `chrome.storage.local`이므로 브라우저 프로필에 종속된다. 구현 시 다음 기능을 고려한다.

- 메모 데이터 JSON 백업
- 메모 데이터 JSON 복원
- 전체 데이터 삭제
- 오래된 내보내기 이력 삭제
- 메모가 없는 페이지 기록 삭제

백업 파일도 로컬 파일로만 다룬다.

## 설치 제한

- 조직 정책에 따라 압축 해제 확장 프로그램 설치가 차단될 수 있다.
- Chrome 내부 페이지에는 확장 프로그램이 동작하지 않는다.
- 파일 URL 접근을 허용하지 않으면 임의의 로컬 HTML에는 오버레이를 주입할 수 없다.
- 배포된 ZIP을 수정하면 무결성 확인이 어려우므로 버전별 ZIP을 보관한다.
